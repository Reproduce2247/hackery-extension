Network rules

fetch/XHR hooks install at document start in the page (MAIN world). Other requests use webRequest. Rules re-inject on save when tabs are open.

Filters

Empty pattern matches anything. Prefix with w: for wildcards (e.g. w:*/api/now/*). All set filters must match.

Set headers

Script receives ctx with phase, method, url, pageUrl, headers, body, status, plus ctx.sharedState (persisted across navigations) and ctx.tabState (per tab). Set ctx.logDetail to surface text in Recent matches. Request scripts also receive decodeBasicAuth(ctx), which returns decoded Basic credentials from headers or URL userinfo. Return modified ctx or null to block.

Untested intent

Header forwarding on redirect (e.g. preserving Authorization when a page-hook redirect changes the XHR URL) is not implemented. webRequest header rules apply to non-fetch traffic; fetch/XHR header changes run in the page hook only. This gap is documented for future work.
